## 1. 변경 동기

현 SSOT (06-integrated-spec.md) 의 코어 메카닉 = 블랙잭 합 누적 (인내 구간 [최소,최대] 안에 합 맞추기). v3~v6 빌드 검증 후 사용자 판단:

- *결정 폭이 좁다* — 매 굴림마다 *진행 vs 멈춤* 2지선다만 반복
- *카드 의미 약함* — 카드 = 합 보정 도구로 격하, 진짜 *결정 공간* 의 일부 ✕
- *적 차별성 약함* — 인내 구간 폭으로만 차별, 매 캐스트 *경험 결* 동일

**대안 검토**: Knucklebones / Farkle / Dicey Dungeons / Yacht 4종 비교 후 사용자가 **Dicey Dungeons 스타일** 채택.

## 2. 새 코어 메카닉

### 2.1 잡힘 정의 (C 모델)

- 적은 *HP* 와 *최대 턴 N* 을 가짐
- 캐스트 = 짧은 *전투 인카운터*. HP 0 도달 = `caught`. N턴 만료 = `escape` (런 HP -1)
- *인내 구간 [최소,최대] 룰 폐기*. F1 (잡힘 등급 = 합 정규화), F2 (정확 일치 +0.2) 폐기

### 2.2 적 분류 (β + 능동 스킬)

| 분류 | HP 범위 | 최대 턴 | 능동 스킬 |
|---|---|---|---|
| 잡동사니 | 5~8 | 1~2 | ✕ |
| 일반 | 10~15 | 2~3 | ✕ |
| 희귀종 | 18~25 | 3~4 | 1개 |
| 보스 | 30~40 | 4~5 | 2~3개 동시 |

(정확 수치는 풀 단계에서. 위는 *스케일 가이드*)

### 2.3 캐스트 구조

```
[캐스트 시작]
  ├ 적 등장 (HP / max_turns / 능동 스킬 [희귀+보스만])
  ├ 슬롯 3장 = 카드 풀에서 *랜덤* 픽 (각 슬롯 = 받는 다이스 *엄격 제약*)
  └ 희귀+보스 한정: 멀리건 1회 (1 슬롯 교체)
↓
[턴 t = 1..N 반복:]
  ├ 다이스 4개 굴림
  ├ (선택) reroll 1회 — 비용: 슬롯 1개 영구 봉인 (이번 캐스트 내 사용 ✕)
  ├ 다이스 3개를 3 슬롯에 매핑 (1개 자동 버림, 슬롯 제약 충족 시만 가능)
  ├ 슬롯 효과 발동 → HP 차감 / 자원 / 디버프 / 시간 보강
  └ (희귀+보스만) 능동 스킬 발동 — *적별 발동 타이밍* (특정 턴 / 매 턴 / N턴마다)
↓
[종료]
  ├ HP 0 = caught → 처분 (분해/매각/보관) → 보상
  └ N턴 만료 = escape → 런 HP -1, 보상 ✕
```

### 2.4 슬롯 *엄격 제약* (Dicey 직역의 핵심)

- 카드 대부분이 *받는 다이스 조건* 을 가짐
- 조건 예시: *어떤 다이스든* / *짝수만* / *홀수만* / *≤ 3* / *≥ 4* / *= 6* / *연속 면 (X 와 X+1)* / *합 = X*
- 조건 충족 ✕ 다이스는 그 슬롯에 매핑 불가 → 변환 카드로 다이스를 조건에 맞게 만들거나 reroll 도박
- 학습 곡선 흡수: FTUE 첫 캐스트 1줄 툴팁 ("각 카드는 받는 다이스 조건이 있어 — 매칭해서 끌어와")

### 2.5 카드 효과 카테고리 (4종, 안티 기둥 #2 정신)

| # | 카테고리 | 역할 | 예시 (구체는 풀 단계) |
|---|---|---|---|
| 1 | **공격** | HP 차감 | 면값 데미지 / 짝수 ×2 / =6 폭딜 |
| 2 | **다이스 변환** | 다이스 면 보정·교환·복제 — 슬롯 제약 매칭 | +1, copy, 면 잠금, 짝↔홀, ≥4 보장 |
| 3 | **자원** | 코인·재료 — 처분·메타 흐름 연결 | 다이스 면값 = 코인, 짝수면 = 재료 |
| 4 | **시간·해제** | 턴 +1, reroll 비용 절감, 봉인 슬롯 해제 | 턴 +1, reroll free 1회, 봉인 해제 |

**방어 카테고리 ✕** — β 가 데미지 패시브를 안 함. 잡동사니 캐스트에서 데드 카드 방지

### 2.6 능동 스킬 카테고리 (3종, 희귀+보스 한정)

| # | 스킬 | 효과 | 대응 카드 카테고리 |
|---|---|---|---|
| 1 | **자기 회복** | 적 HP +N | 공격 (더 빨리 깎기) |
| 2 | **슬롯 봉인** | 플레이어 슬롯 1개 K턴 잠금 | 시간·해제 (해제 카드) |
| 3 | **다이스 면 강제** | 다이스 1개 자동 = 1 (또는 특정 면) | 다이스 변환 (변환·copy 대처) |

발동 타이밍 (특정 턴 / 매 턴 / N턴마다) 은 적별 디테일 — 풀 단계에서.

### 2.7 멀리건

- *희귀+보스 한정* 캐스트 시작 시 1회 무료 (3 슬롯 중 1장 교체)
- 메타 노드 "멀리건 +1" 으로 일반 캐스트도 강화 가능
- 일반 적 풀 미스매치는 *도주 -1 HP* 로 흡수 (런 8 캐스트 안에 *몇 번 도주는 수용*)

## 3. 정점 모먼트 재정의 (§B 정점 모먼트)

| # | 현 (블랙잭) | 신 (다이스 매핑) |
|---|---|---|
| 1 | "한 박자: 합이 인내 최소를 막 넘긴 직후 진행/멈춤" | **"의외 매핑 발견"** — 같은 3 슬롯이라도 굴림에 따라 *비자명 매핑* 발견. 손가락 떨림 |

| 3 | "보스 마지막 핸드 광기" | **"보스 마지막 턴 reroll 도박"** — 보스 N턴 만료 직전, reroll 비용으로 슬롯 1 봉인하고 재굴림 한 방 노리는 광경 |

## 5. 폐기·신규 룰 (§B 룰 카탈로그)

### 5.1 폐기 룰
- R-1 인내 구간, R-2 진행/멈춤, R-3 도주 (재정의), R-4 버스트 (폐기), R-5 잡힘 (재정의), R-6 정확 일치, R-7 카드 핸드 (재정의)

### 5.2 신규 룰 (스케치, /cp-redo 6 에서 정식 번호 부여)

- **N-1 다이스 굴림**: 매 턴 4 d6 굴림. 캐스트 시작 시 자동 1회
- **N-2 매핑**: 굴린 다이스 4개 중 3개를 슬롯 3개에 *제약 충족* 매핑. 1개 자동 버림. 매핑 확정 → 효과 발동
- **N-3 슬롯 제약**: 카드별 정의. 매핑 시 위반 매핑 불가
- **N-4 reroll**: 매 턴 1회 — 비용: 임의 슬롯 1개 *영구 봉인* (이번 캐스트 내 사용 ✕)
- **N-5 캐스트 종료**: HP 0 → caught / max_turns 만료 → escape
- **N-6 멀리건**: 희귀+보스 캐스트 시작 시 1회 무료 슬롯 교체. 메타 노드로 일반 캐스트 확장
- **N-7 능동 스킬**: 희귀+보스만. 발동 타이밍 적별 다양

## 8. UI 영향 (§D)

```
┌────────────────────────────┐
│ ▓ safe area top            │
├────────────────────────────┤
```

- 다이스 *드래그* 또는 *탭 후 슬롯 탭* — 슬롯에 할당
- 슬롯 *long press* — 카드 상세 (제약·효과·플레이버)
- *매핑 확정* 버튼 — 효과 발동 + 다음 턴

## 9. 미루는 디테일 (코어 검증 후)

- 카드 풀 시작 N장 / 카테고리당 분포 / 등급 (C/R/L) / 구체 효과 수치
- 적 HP 정확 수치 (티어별 변동 폭)
- 능동 스킬 구체 카탈로그 (이름·수치·발동 타이밍)
- 메타 트리 노드 재구성 (멀리건 +1, 시작 슬롯 +1, 카드 풀 추가, 재료 → 합성 등)
- 정점 모먼트 #1·#2·#3 의 *세부 발현* (FX·UI·SFX)
- art-bible §2.4 카드 일러스트 슬롯 (제약 카드 시각화 — *조건 표식*)

## 10. 빌드 라운드 분할

코어 전면수정은 v7 단일 라운드로 처리 ✕ (스코프 과다). 분할:

| 라운드 | 범위 |
|---|---|
| **v7** | 신 s1 (다이스 매핑) + 신 s2 (슬롯 풀 픽) + game_screen 재작성. 일반 적만, 능동 스킬·멀리건 ✕. 기존 v3~v6 smoke 폐기·신규 |
