## TL;DR

B.F. Skinner의 1930~50년대 강화 스케줄 연구는 **변동 비율 강화(Variable Ratio Reinforcement)**가 가장 강한·가장 지속적 행동을 유발한다는 사실을 입증했다. 이 원리가 슬롯머신·소셜 미디어·F2P 가챠의 공통 동력이며, 도파민의 **기대 회로**를 자극한다(쾌락이 아닌 기대가 핵심). 게임 디자이너는 이 메커니즘을 학습·동기·도전 보강에 윤리적으로 활용할 수 있지만, 도박 행동 패턴 유도와는 인접한다. 평가자는 GDD가 변동 강화를 어떻게 활용하고, 사용자 보호 가드를 두고 있는지를 본다.

## 1. 이론 배경

### 1.1 Skinner의 4가지 강화 스케줄

| 스케줄 | 정의 | 행동 패턴 |
|--------|------|---------|
| **고정 비율(FR)** | N회 행동마다 보상 | 보상 후 잠시 멈춤 |
| **고정 간격(FI)** | N초마다 보상 | 보상 직전에 행동 ↑ |
| **변동 간격(VI)** | 무작위 시간마다 보상 | 일정 빈도로 지속 |
| **변동 비율(VR)** | 무작위 횟수마다 보상 | **가장 강한·가장 지속** |

### 1.2 VR이 가장 강력한 이유

- **예측 불가성**: 다음 행동이 보상일 수 있다는 기대.
- **소거 저항**: 보상이 끊겨도 행동 지속 — Skinner는 "수백 회 시도까지" 관찰.
- **도파민**: 기대 단계에서 도파민 분비 → 행동 강화.

### 1.3 도파민의 진실

- 통념: "보상이 즐거움을 만든다."
- 실제: 도파민은 **기대(Anticipation)** 단계에서 가장 많이 분비.
- 보상 자체보다 "보상이 올 것이라는 학습된 기대"가 핵심.
- 이것이 "Wanting ≠ Liking" 이론.

## 2. 게임에서의 변동 강화

### 2.1 흔한 적용

- **랜덤 드롭**: 적이 무작위로 아이템 떨굼.
- **크리티컬 히트**: 무작위로 큰 대미지.
- **가챠**: 결제로 무작위 캐릭터·아이템.
- **루트 박스**: 결제 또는 진행으로 무작위 보상.
- **이벤트**: 무작위 등장 이벤트.

### 2.2 다중 스케줄 중첩

Dr. Luke Clark(영국 도박 연구자):
> "현대 게임은 여러 변동 비율 스케줄을 동시에 중첩한다. 레벨업, 캐릭터 진행, 희귀 추가, 게임 통화, 모두 동시에."

→ 이 다중 중첩이 게임의 강한 매력의 원천이자 윤리적 위험의 진원지.

### 2.3 Compulsion Loop (강박 루프)

> 사용자가 반복하도록 설계된 행동 사슬, 도파민 보상 순환을 만든다.

- 게임 디자인 의도적 활용.
- 사용자가 "그만두어야 하는데 못 그만두는" 상태.
- 인터넷·도박 중독과 유사한 패턴.

## 3. Near-Miss Effect (근접 실패)

### 3.1 정의

> 보상에 거의 도달했지만 못 받은 상황은 행동을 더욱 강화한다.

### 3.2 게임 적용

- **CS:GO 케이스 오프닝**: 회전 릴이 SSR 옆에서 멈춤.
- **가챠 애니메이션**: 빛이 화려해지다가 일반으로.
- **퍼즐 게임**: "한 수만 더 있었으면 깰 수 있었는데".

### 3.3 위험

- 도박 중독 메커니즘과 정확히 일치.
- 청소년·취약 사용자에게 특히 강한 영향.

## 4. F2P 게임 사례 분석

### 4.1 *Genshin Impact*

- Primogems → 무작위 캐릭터·장비.
- 시간 한정 픽업 배너.
- Pity 시스템(연속 실패 시 보장)으로 일부 윤리 보강.

### 4.2 *Clash of Clans*

- 빌드 쿨다운(시간 제약).
- 일일 보상 → 변동 간격 + Loss Aversion.
- 시간 단축 결제 유도.

### 4.3 *Candy Crush Saga*

- 무작위 부스터 드롭.
- 라이프 5개 + 시간 제약.
- 첫 결제 진입을 자연스럽게.

## 5. 윤리적 활용 vs 위험한 활용

### 5.1 윤리적 — 학습·도전 강화

- 적이 무작위로 아이템 드롭 → 탐험 동기.
- 크리티컬 히트 → 전투 흥분.
- 무작위 이벤트 → 신선함.
- **무료 진행 경로 보장 + 확률 공개**가 핵심 조건.

### 5.2 윤리적 — 학습 곡선 변형

- 학습 콘텐츠에 적용한 "교육 게임"은 변동 강화로 학습 동기 강화 가능.
- 단, 주된 목적이 학습이고 무작위는 양념일 때 윤리적.

### 5.3 위험 — 결제 의존

- 강력 캐릭터가 가챠로만 획득 가능.
- 결제하지 않으면 코어 콘텐츠 진행 불가.
- 픽업 + 일반 가챠 결합으로 실질 확률 모호.

### 5.4 위험 — 청소년 노출

- 미성년자 결제 한도 없음.
- Pity 시스템 부재.
- 가챠 외 대안(직접 구매, 교환) 없음.

## 6. 사용자 보호 가드

### 6.1 확률 공개

- 가챠 확률을 GDD와 게임 내 모두 명시.
- 픽업 + 일반 결합 시 실질 확률 명시.
- 한국·중국 등에서 법적 의무.

### 6.2 Pity System

- 연속 N회 실패 시 보장 보상.
- 사용자 보호 + 흥미 유지.
- 권장: SSR 90회 이내 보장.

### 6.3 결제 한도

- 일/월 한도 옵션 제공.
- 미성년자 자동 한도(법적 제한 + 가족 알림).
- 한도 도달 시 즉시 차단.

### 6.4 환불 정책

- 명확한 환불 절차.
- 미성년자 부모 환불 가능.

### 6.5 자기 배제

- 사용자가 가챠 시스템 차단 옵션.
- 일정 기간 결제 차단.

## 7. GDD 평가 체크리스트

### 7.1 메커니즘 명시

- ✅ 변동 강화를 사용하는 시스템(랜덤 드롭·가챠·루트박스) 모두 명시
- ✅ 각 시스템의 확률 분포가 명시
- ✅ 다중 스케줄이 중첩되는 구간 분석되었는가

### 7.2 윤리 가드

- ✅ Pity 시스템이 있는가 (연속 실패 보장)
- ✅ 가챠 확률 공개 — 게임 내 + 스토어 페이지
- ✅ 일·월 결제 한도 옵션
- ✅ 미성년자 보호 가드 (한도, 가족 알림)
- ✅ 환불 정책 명시
- ❌ 위 5개 중 1개라도 부재면 윤리 미달

### 7.3 무료 경로

- ✅ 무료 사용자도 코어 즐거움 도달 가능
- ✅ 가챠 외 획득 경로(직접 구매, 이벤트, 교환) 존재
- ✅ 1년 플레이로 가챠 풀의 일정 % 자연 획득 가능
- ⚠️ 강력 캐릭터가 사실상 결제 전용

### 7.4 Near-Miss 사용

- ✅ 사용된다면 사용자 알림 (예: "거의 다 됐어요!"가 너무 자주 안 뜨도록)
- ⚠️ Near-Miss 연출이 도박 메커니즘과 동일 수준
- ❌ 청소년 대상 게임에서 Near-Miss 강한 연출

## 8. 작성 가이드 — 윤리적 변동 강화

### 8.1 변동 시스템 명세

```yaml
gacha_system:
  banner_id: spring_2026
  duration: 14_days
  
  rates:
    SSR: 1.5%
    SR: 8.5%
    R: 90.0%
  
  pity:
    soft_pity_start: 75
    hard_pity: 90  # 90회 안 SSR 보장
  
  pickup:
    rate_within_SSR: 50%
    actual_pickup_rate: 0.75%
  
  effective_rate_disclosure: true
  
  protection:
    daily_pull_limit_option: true
    minor_monthly_cap: 100_usd
    refund_policy: linked_to_terms
```

### 8.2 의사결정 지원 워크숍

GDD 작성 단계에서 다음 질문에 답하기:

1. 우리 게임은 변동 강화를 어디에 사용하는가?
2. 그것이 학습/도전/탐험을 위한 것인가, 매출을 위한 것인가?
3. 사용자가 "재미있게 즐길 수 있는 옵션"인가, "결제하지 않으면 진행 불가"인가?
4. 미성년자가 이용할 수 있다면 어떤 보호가 있는가?
5. 사용자가 결제 후 후회한다면 어떻게 회복할 수 있는가?

## 9. 안티패턴

- **확률 비공개**: 표기 부재 또는 "약 N%" 같은 모호 표현.
- **Pity 부재**: 무한 결제 가능, 보장 없음.
- **결제 한도 부재**: 미성년자 보호 가드 없음.
- **다중 가챠 중첩**: 사용자가 실제 확률을 계산할 수 없게.
- **Near-Miss 남용**: 도박 연출 그대로 게임에 적용.
- **무료 경로 차단**: 강력 캐릭터가 결제로만.
- **Sunk Cost 강요**: "이만큼 했는데 한 번 더!" 메시지.

## 10. 다른 이론과의 관계

- **Octalysis**: Drive 7(Unpredictability)의 메커니즘적 기반.
- **Loss Aversion**: 가챠 픽업 종료 압박은 Loss Aversion 결합.
- **Sunk Cost**: 누적 결제가 매몰 비용으로 작동.
- **SDT**: 외적 보상(가챠 결과) 의존이 PENS 자율성·유능성 침식.
