# 플레이어 여정 매핑

> 게임은 *시간 위의 경험*. 플레이어가 만나는 순간들을 시간축으로 펼쳐서 본다.
> 컨셉 단계에서 여정을 그리지 않으면 "재미는 있는데 끝까지 못 가는 게임" 이 됨.

## 핵심 원리

플레이어 여정은 3 개 시간 스케일로 동시에 본다:

1. **세션 아크** (1 게임 세션, 분~시간)
2. **런 아크** (한 진행 단위, 게임마다 다름)
3. **진보 아크** (전체 플레이 라이프, 일~월)

각 스케일에서 "어떤 감정·결정·정보가 어떻게 펼쳐지는가" 를 매핑.

---

## 1. 세션 아크

한 번 앉아서 플레이하는 단위. 보통 10분~2시간.

### 표준 5 단계

```
[1. 진입]    →  [2. 워밍업]  →  [3. 코어]    →  [4. 정점]    →  [5. 마무리]
   3~10초       30초~1분        5~30분       1~5분         30초~2분
```

| 단계 | 목적 | 핵심 감정 |
|------|------|----------|
| 1. 진입 | 게임 켜짐 → 플레이 시작 | 안도·기대 |
| 2. 워밍업 | 컨트롤·환경 적응 | 익숙함 회복 |
| 3. 코어 | 메카닉 깊은 활용 | 몰입·결정 |
| 4. 정점 | 절정 모먼트 | 긴장·쾌감 |
| 5. 마무리 | 결과·다음 의도 | 만족·도전 욕구 |

### 매핑 양식

```markdown
## 세션 아크 (목표: 30분 평균)

### 1. 진입 (3~10초)
- 시작 화면 → 시작 클릭 → 로딩 → 게임 화면
- 중단점: 메인 메뉴에 머물기 < 5초
- 핵심 감정: 즉시 시작 가능한 안도

### 2. 워밍업 (30초)
- 캐릭터 이동·기본 액션 1회씩
- 화면에 ★ 1개 표시되어 클릭 → 첫 캐치 성공
- 핵심 감정: 컨트롤 손에 익음

### 3. 코어 (15~25분)
- 6~10 런 반복
- 매 런 마다: 배치 → 캐치 → 결과 → 업그레이드 선택 → 재시작
- 핵심 감정: 깊은 몰입, 결정의 연속

### 4. 정점 (1~3분)
- 특정 런에서 "최고 점수 갱신" 또는 "전설 캐치"
- 화면 정지·BGM duck·황금 빛 효과
- 핵심 감정: 긴장 → 쾌감

### 5. 마무리 (30초~1분)
- 결과 화면 → 진보 표시 → "한 판 더?" 또는 종료
- 핵심 감정: 만족 + 다음 도전 욕구
```

## 2. 런 아크

한 *진행 단위*. 게임 장르에 따라 다름:
- 로그라이트: 한 던전 입장 ~ 사망/클리어
- 슈퍼 마리오: 한 스테이지 시작 ~ 완료
- RPG: 한 퀘스트 수락 ~ 완료
- 아케이드: 한 라운드 시작 ~ 종료

### 표준 4 단계

```
[설정]  →  [전개]  →  [정점]  →  [결산]
 1줄      반복     1~2회      1줄
```

### 매핑 양식

```markdown
## 런 아크 (목표: 60초 라운드)

### 설정 (3초)
- 화면 페이드인, BGM 시작
- 카운트다운 3-2-1
- 첫 오브젝트 등장

### 전개 (40초)
- 오브젝트 등장·캐치 반복
- 난이도 점진 상승 (스폰 간격 ↓, 동시 활성 ↑)
- 콤보 누적 가능
- 중반(30초) 즉, "한 번의 큰 결정" (LEGENDARY 등장 가능)

### 정점 (10초, 50~60초 구간)
- 스폰 가속 + 다중 LEGENDARY 가능
- 화면 흔들림 + BGM 가속
- "마지막 한 번의 캐치" 의 긴장

### 결산 (5초)
- 종료 사운드
- 점수 카운트업 애니메이션
- 결과 화면으로 페이드
```

### 정점의 위치

게임 장르에 따라 정점 위치 다름:
- **단조 상승형** (러너): 정점 = 끝 직전
- **수직형** (보스전): 정점 = 끝
- **물결형** (RPG): 작은 정점 여러 개 + 큰 정점 1개
- **오픈형** (샌드박스): 사용자 결정

→ 자기 게임의 정점 위치를 *명시적으로* 결정.

## 3. 진보 아크

전체 플레이 라이프. 첫 플레이 ~ 졸업까지.

### 표준 단계

```
[FTUE]  →  [러닝]  →  [숙련]  →  [마스터]  →  [완성/졸업]
 첫 30분   1~5h      5~20h     20~50h     50h+
```

### 매핑 양식

```markdown
## 진보 아크 (목표: ~30시간 컨텐츠)

### FTUE (첫 30분)
- 메카닉 1개씩 도입 (한 번에 한 개)
- 첫 LEGENDARY 캐치 의도적 발생 (15분 시점)
- 첫 업그레이드 의도적 발생 (20분 시점)
- 핵심 감정: 안도·발견

### 러닝 (1~5시간)
- 모든 메카닉 노출 완료
- 업그레이드 트리 시작
- 첫 "벽" (어려운 보스 또는 도전)
- 핵심 감정: 학습·성장

### 숙련 (5~20시간)
- 전략 다양화 (여러 빌드 시도)
- 도감 30~60% 완성
- 자신만의 스타일 형성
- 핵심 감정: 자기 표현·통제감

### 마스터 (20~50시간)
- 도감 80%+ 완성
- 최고 난이도 도전
- 매크로 전략 (메타-게임)
- 핵심 감정: 마스터리·도전

### 완성/졸업 (50h+)
- 모든 컨텐츠 소진
- 자기만의 챌린지 또는 다른 게임으로
- 핵심 감정: 만족·작별
```

### Churn (이탈) 지점 식별

각 단계마다 *왜 그만두는가*:

| 단계 | 흔한 이탈 원인 |
|------|---------------|
| FTUE | 컨트롤 못 익힘, 첫 30분 재미 못 느낌, UI 혼란 |
| 러닝 | "벽" 너무 높음 또는 너무 낮음 |
| 숙련 | 다양성 부족 — 모든 런이 비슷 |
| 마스터 | 컨텐츠 소진 — 새로움 없음 |

→ 각 단계의 이탈 원인 식별 + *완화 메카닉* 설계.

## 감정 곡선 (Emotion Curve)

각 아크에서 감정 강도를 그래프로:

```
긴장도 (Tension)
  ▲
  │              ╱╲
  │            ╱    ╲
  │          ╱        ╲___ 정점 (Peak)
  │        ╱
  │      ╱  ← 코어 (Core)
  │    ╱
  │   /  ← 워밍업
  │ /
  └────────────────────────▶ 시간
   진입  워밍업  코어  정점  마무리
```

### 곡선 점검

- 단조 증가만 → 지침
- 정점 너무 빨리 → 정점 후 하락이 길어 지루함
- 정점 없음 → 기억에 남는 모먼트 부재
- 정점 너무 늦게 → 도달 전 이탈

**목표 곡선**: 점진 상승 + 마지막 1/4 에 정점 + 짧은 하강 (마무리).

---

## 정보 발견 곡선 (Information Drip)

플레이어가 *언제* *어떤* 정보를 알게 되는가:

```
시간    정보·메카닉
─────────────────────────
00:00   기본 컨트롤 (이동·캐치)
01:00   첫 일반 캐치 ← 타격감
03:00   첫 LEGENDARY 등장 ← "특별한 게 있다"
05:00   첫 콤보 인디케이터 ← 콤보 시스템 인지
10:00   첫 업그레이드 선택 ← 메타 진보 인지
20:00   첫 "벽" — 어려운 라운드 ← 전략 필요성
30:00   도감 시스템 노출 ← 장기 목표
```

### 원칙

- **한 번에 한 메카닉**: 동시 다중 도입 금지
- **첫 30분 안에 코어 메카닉 모두 노출**: 너무 늦으면 이탈
- **메타 시스템은 코어 안정화 후**: 업그레이드·도감은 코어 익숙해진 다음
- **선택의 기회**: 정보 발견 후 *플레이어 결정* 으로 이어져야

---

## 매핑 시점

본 파이프라인에서:
- **단계 1 (컨셉)**: 세션 아크 + 정점 위치 + 감정 곡선 *대략* 결정
- **단계 5 (확장)**: 모든 3 아크 *상세* 매핑
- **단계 6 (통합 명세)**: D. UX 흐름 섹션에 매핑 명시

## 안티패턴

### 1. "아무때나 시작 가능" 만 강조
세션 아크 = "그냥 플레이" 식으로 단조.
→ 정점 부재, 기억 안 남음.

### 2. FTUE 압박
첫 5분에 모든 메카닉 노출 → 인지 부하 폭주.

해결: 한 번에 한 메카닉. 도입 간격 1분 이상.

### 3. 진보 아크 50h+ 가정
실제 완주 < 5%. 그러나 95% 의 컨텐츠가 5h+ 에 있음.
→ 95% 가 못 본 컨텐츠.

해결: 첫 5h 에 *충분한 만족*. 그 이후는 보너스.

### 4. 정점 위치 없음
"플레이어가 알아서 정점 만든다" → 대부분 정점 없이 끝남.

해결: 정점 위치 *디자이너가 보장*.

## 검증 체크리스트

- [ ] 세션 아크 5단계 모두 명시 (시간 + 감정)
- [ ] 런 아크 4단계 + 정점 위치 명시
- [ ] 진보 아크 5단계 + 단계별 이탈 원인 식별
- [ ] 감정 곡선 그래프 또는 표
- [ ] 정보 발견 곡선 (시간 ↔ 메카닉 노출)
- [ ] 첫 5h 에 충분한 만족 (장기 컨텐츠와 별개)
