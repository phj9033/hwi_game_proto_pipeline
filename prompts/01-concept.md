# 단계 1 — 게임 컨셉 정립 (대화 모드)

## 목적
사용자와의 짧은 대화로 게임 컨셉을 한 장 분량으로 정리한다. 이 문서는 이후 단계 모두의 출발점이다.

## 산출물
`workspace/<slug>/01-concept.md`

## 진행 원칙
- **섹션 단위 incremental write**: 한 섹션 합의되면 즉시 파일에 추가. 통째로 작성 금지.
- **질문은 한 번에 1~2개**: 사용자를 압박하지 않는다.
- **선택지 제시**: 가능하면 2~4개 옵션과 트레이드오프 보여주고 사용자가 결정.
- **간결**: 컨셉 단계는 1~2페이지면 충분. 디테일은 5단계에서 채운다.

## 필수 섹션 (작성 순서)

### 1. 엘리베이터 피치 (1~2문장)
**질문 패턴**:
- "어떤 게임을 만들고 싶으신가요? 한두 문장으로 요약하면?"
- (사용자 답이 모호하면) 비교 대상, 핵심 동사, 타겟 톤 확인

**출력 형식**:
> "[X 같은 핵심 메카닉]을 [Y 한 톤/세계관]에서 [Z 한 플레이 길이]로 즐기는 게임."

### 2. 핵심 판타지 (3~5줄)
**질문 패턴**:
- "이 게임을 플레이하는 사람이 자기 자신이 *무엇이* 되었다고 느끼면 좋을까요?"
- "그 순간의 감정을 한 단어로 한다면?"

**출력 예시**:
> "플레이어는 [역할/존재]가 되어 [핵심 동사]를 한다. 그 과정에서 [감정 1], [감정 2]를 느낀다."

### 3. 게임 기둥 3개 (각 1줄, 짧은 슬로건)
**질문 패턴**:
- "이 게임이 절대 양보할 수 없는 가치 3개를 뽑는다면?"
- (응답에서 너무 추상적인 게 있으면) "그게 게임 메카닉으로는 어떻게 나타나죠?"

**출력 형식**:
| # | 슬로건 | 메카닉적 함의 |
|---|--------|--------------|
| 1 | "..." | ... |
| 2 | "..." | ... |
| 3 | "..." | ... |

### 4. 코어 루프 (3~6단계 순환)
**질문 패턴**:
- "한 번의 플레이 사이클이 어떻게 흘러가나요? 시작 → ... → 끝."
- "그 사이클의 핵심 결정의 순간은 언제죠?"

**출력 형식**:
```
[행동 A] → [정보/피드백] → [의사결정] → [행동 B] → [보상/결과] → (반복)
```
+ 1줄 코멘트: 어디가 "재미의 정점"인가.

### 5. 타겟 오디언스 (Bartle 분포 + 비교 게임)
**질문 패턴**:
- "어떤 플레이어가 이 게임에 빠질까요? Achiever / Explorer / Socializer / Killer 비중으로 말한다면?"
- "유사한 감각을 주는 게임 2~3개?"

**출력 형식**:
- Bartle 분포: A:__% E:__% S:__% K:__%
- 비교 게임 + 어떤 면이 같고 어떤 면이 다른지

### 6. USP (Unique Selling Proposition, 1~2 문장)
**질문 패턴**:
- "비교 게임들과 결정적으로 다른 한 끗은 무엇인가요?"
- (애매하면) "그 차이가 트레일러 30초에 보이나요?"

**출력 형식**:
> "기존 X 장르는 Y 한 한계가 있다. 이 게임은 [한 끗]으로 그 한계를 뒤집는다."

## 작성 후 검증 (LLM 자기 점검)
모든 섹션 완료되면 다음을 사용자에게 한 번에 보고:
1. 6개 섹션 모두 한 화면 요약으로 보여주기
2. 자기 점검 질문:
   - 엘리베이터 피치 → 코어 루프 → USP 가 한 방향으로 일관되는가?
   - 게임 기둥 3개가 코어 루프와 부합하는가?
3. 사용자 최종 OK 받으면 단계 완료. 단계 2 (분기 초안) 으로 진행 안내.

## 출력 톤
- 한국어
- 마크다운 헤더 사용 (## 엘리베이터 피치 …)
- 추상적 단어("재미있는", "독특한") 자제, 구체적 동사·이미지로
